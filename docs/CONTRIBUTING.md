# แนวทางการร่วมพัฒนาโปรเจกต์ / Contributing Guide

## 🇹🇭 ภาษาไทย (Thai)

โปรเจกต์ **TH_DESK** และ **TH_DESK Server** ยินดีต้อนรับนักพัฒนาและผู้ใช้งานทุกคนที่ต้องการมีส่วนร่วมในการพัฒนา ปรับปรุงฟีเจอร์ หรือแจ้งปัญหาการใช้งาน!

### ช่องทางการมีส่วนร่วม
1. **การแจ้งบั๊กและปัญหาการใช้งาน (Reporting Bugs):** เปิดแจ้งได้ที่เมนู [Issues](https://github.com/kuromineko/TH_DESK/issues) โดยระบุรุ่นของ Windows, ขั้นตอนที่ทำให้เกิดปัญหา และภาพหน้าจอประกอบ
2. **การเสนอฟีเจอร์ใหม่ (Feature Requests):** สามารถเปิด Issue เพื่อเสนอไอเดียสำหรับปรับปรุงทั้งฝั่ง Client (`TH_DESK`) และฝั่งตัวจัดการเซิร์ฟเวอร์ (`TH_DESK_Server`)
3. **การส่งโค้ดแก้ไข (Pull Requests):**
   * Fork โปรเจกต์ไปยังบัญชีของคุณ และสร้าง Branch ใหม่สำหรับฟีเจอร์หรือการแก้ไขบั๊ก
   * ตรวจสอบให้แน่ใจว่าโค้ดสามารถคอมไพล์ผ่านและทำงานได้ถูกต้อง
   * ส่ง Pull Request เข้ามาที่ Branch หลักของโปรเจกต์

### ข้อกำหนดด้านสัญญาอนุญาต
การส่งโค้ดเข้าร่วมในโปรเจกต์นี้ ถือว่าคุณยินยอมให้เผยแพร่ผลงานของคุณภายใต้สัญญาอนุญาต **GNU Affero General Public License v3.0 (AGPL-3.0)** เช่นเดียวกับตัวโปรเจกต์หลัก

## 🇬🇧 English

**TH_DESK** and **TH_DESK Server** welcome contributions, bug reports, and feature suggestions from everyone in the community!

### How to Contribute
1. **Reporting Bugs:** Open a ticket on the [Issues](https://github.com/kuromineko/TH_DESK/issues) page with your Windows version, reproduction steps, and screenshots.
2. **Feature Requests:** Feel free to open an Issue to suggest improvements for either the Client (`TH_DESK`) or the Server Manager (`TH_DESK_Server`).
3. **Pull Requests:**
   * Fork the repository and create a new branch for your feature or bugfix.
   * Ensure your changes compile cleanly and adhere to project standards.
   * Submit a Pull Request to the main branch.
